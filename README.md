# Verificador de Idade

Aplicativo desktop em Python com CustomTkinter para verificar maioridade e salvar cadastros localmente.

## Arquivos

- `main.py`: aplicativo.
- `dados_salvos.json`: cadastros locais; este arquivo e ignorado pelo Git por poder conter dados pessoais.
- `requirements.txt`: dependencia do projeto.

## Executar

Instale a dependencia e inicie o aplicativo:

```powershell
python -m pip install -r requirements.txt
python main.py
```

Os cadastros ficam no arquivo `dados_salvos.json`, na mesma pasta do aplicativo.
